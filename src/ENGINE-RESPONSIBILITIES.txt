WINDPOST + BASEPLATE DESIGNER
MODULAR ENGINE BUILD — 11 SEPTEMBER 2026 V.03
============================================================

PURPOSE
-------
This folder is a separate modular copy of the proven Windpost Selector and
Detailing software. The structural formulae, section databases, dimensions,
drawing geometry, CAD layers and A4 production output are retained.

The software is divided by responsibility. Calculation engines do not draw.
Geometry engines do not select sections. Drawing engines do not calculate
capacity. UI controllers only read controls, call engines and display results.

The standalone launcher is generated from index.html by build-standalone.js.
Edit the small source engines, run the tests, and then rebuild the standalone
file. Do not hand-edit Windpost-Selector-Full.html.


1. CONFIGURATION AND DATA ENGINES
---------------------------------
js/config.js
  Stores global engineering conversion factors, material density, tie
  strengths and fixed configuration values.

js/data/windpost-parameters.js
  Holds the generated design constants originating from the Excel database.

js/data/l-section-database.js
  Holds every permitted L-post catalogue section and its section properties.

js/data/u-section-database.js
  Holds every permitted U-post catalogue section and its section properties.

js/data/standard-section-heights.js
  Holds the standard reference heights used by catalogue and checking tools.

js/data/du-section-database.js
  Holds the DU (double-U) catalogue: two U channels welded web to web,
  properties = 2 x U. Simply supported only. Generated from
  WINDPOST_CALCULATOR_V2.xlsx.

js/data/i-section-database.js
  Holds the I (flat plate a x t) catalogue built into the inner leaf.
  Simply supported only, shear ties only, no outer tie. Generated from
  WINDPOST_CALCULATOR_V2.xlsx; reproduces the former hardcoded I table.

js/data/connections-database.js
  Holds the connection library (head/base fixings per family with codes,
  descriptions, material class, bracket weights, post bolts and connection
  bolt SKUs per bolt family), the cantilever base-plate types U-A..U-G /
  L-A..L-G with capacity bands and plate/stiffener geometry, the anchor
  capacity table (RGM, FAZ II, FAZ II Plus), the bolt-quantity matrix and the
  per-section standard plate weights. I-post rows are copies of the U rows.

js/data/section-profiles.js
  Provides one common lookup interface for U, L, DU and I sections and
  converts stored catalogue properties into calculation-ready values. Also
  declares which families may be cantilevered (U and L only).

js/data/tie-profiles.js
  Stores confirmed fabrication dimensions for the separate connection-tie
  prototypes. It contains EDC25-100 through EDC25-375 with their stored actual
  lengths and corrected connection ends, plus the 168 × 10 × 1.5 mm two-way
  shear tie with its four R3-ended slots and mirrored centre engagement.

js/utils.js
  Contains shared number formatting and support/load label helpers.


2. WINDPOST ANALYSIS AND SELECTION ENGINES
------------------------------------------
js/engines/secant-modulus-engine.js
  Solves the stainless-steel secant modulus using the established material
  model and proof-strength inputs.

js/engines/load-case-engine.js
  Applies the selected support and load arrangement and calculates the
  corresponding windpost load effects.

js/engines/tie-capacity-engine.js
  Calculates the number of tie levels and their total design resistance.

js/engines/result-selection-engine.js
  Compares deflection, bending, tie and optional connection limits and returns
  the governing ultimate design capacity and governing description.

js/engines/windpost-calculation-engine.js
  Coordinates the secant-modulus, load, deflection, bending and tie-capacity
  calculations for one selected windpost.

js/engines/outer-tie-selection-engine.js
  Calculates post placement, cavity gap, inner tie type, outer EDC tie type and
  outer-leaf embedment from the wall construction and selected section.

js/engines/automatic-selection-engine.js
  Evaluates the catalogue in order and selects the first suitable U, L, DU or
  I section. It also supports manual section checking. DU and I cantilevers
  are rejected.

js/engines/connection-selection-engine.js
  Resolves head and base connection codes from the chosen fixings, the bolt
  SKU for the chosen bolt family (load-dependent anchors use the capacity/2
  rule against the anchor table), bolt counts from the quantity matrix,
  the cantilever standard plate type from the base moment (W.H for a top
  point load, W.H/2 for a UDL) with plate + stiffener weight varying with the
  selected section depth, post weight (blank x t x L x density), special
  connection overrides, ties per level (DU = 2), debonding sleeves and the
  total weight per post and for all posts.


3. CANTILEVER BASEPLATE STRUCTURAL ENGINES
------------------------------------------
js/engines/baseplate-config.js
  Stores fixed anchor, material, weld, plate and design configuration values
  used by the cantilever baseplate checks.

js/engines/baseplate-bolt-engine.js
  Calculates RGM 12 bolt-group forces, lever arms and moment resistance.

js/engines/baseplate-leff-engine.js
  Calculates effective T-stub lengths for the relevant bolt layout.

js/engines/baseplate-tstub-engine.js
  Calculates the equivalent T-stub failure modes and governing tension
  resistance.

js/engines/baseplate-stiffener-engine.js
  Calculates triangular stiffener height, section properties and resistance.

js/engines/baseplate-shear-engine.js
  Checks anchor shear and plate shear resistance.

js/engines/baseplate-check-engine.js
  Combines bolt, local plate bending, rigidity, T-stub, stiffener and shear
  checks and returns utilisation and pass/fail results.

js/engines/baseplate-sizer-engine.js
  Stage 1: rebuilds the standard plate type for the base moment (U-A..U-G /
  L-A..L-G from connections-database) as a bolt layout + stiffener and runs
  the full check set; if it passes it is the design ("standard"). If only the
  base + stiffener bending check fails, the standard plate and bolts are kept
  and the stiffener height is raised ("standard (stiffener raised)").
  Stage 2: otherwise auto-sizes (fewest rows, thinnest, shortest) with the
  standard practice: pitch <= 150 mm, 200 wide up to 260 long then 220,
  8 thick then 10 from 390 long, local plate bending always enforced.

js/engines/baseplate-design-engine.js
  Public cantilever baseplate facade. It validates the requested actions,
  calls the smaller checking/sizing engines and returns the final design.

SAFE CHANGE PROCEDURE
---------------------
1. Change only the engine responsible for the required task.
2. Run node tests/baseplate-tests.js.
3. Run node tests/l-section-prototype-tests.js.
4. Run node tests/run-tests.js and the remaining specialist tests.
5. Run node build-standalone.js.
6. Confirm Windpost-Selector-Full.html contains the new engine.
7. Open OPEN-WINDPOST-SELECTOR.cmd.

This separation is intended to prevent a drawing-only change from altering
structural selection logic, and to prevent a calculation change from silently
changing fabrication geometry.

3D VIEW — BASE PLATE / STIFFENER JUNCTION (11 Sep 2026)
cavity-wall-3d-engine.js draws with a painter's algorithm. The post leg was
one full-height quad, so at some azimuths its centroid sat in front of the
stiffener and painted over it at the junction. Fix:
  - model.sortPlanes: separating planes (plate top z=0, post leg plane) and
    per-item planeSides; draw order = plane bands from the view direction
    first, centroid depth second (baseplate behind, post/stiffener/anchors in
    front of the plate; stiffener vs post decided by the leg plane).
  - sliceFace(): post extrusion faces are sliced at render time into <=150 mm
    strips (hole-aware), so each strip sorts by its own depth.
  - anchorBolts(): washer + hex head + shank at each anchor centre (group
    "anchors") so the plate reads as fixed.
Verified visually through eight orbits/elevations at 900 and 2670 mm.
tests/l-section-prototype-tests.js asserts planeSides, sortPlanes and the
anchor face count (4 x (3x2 + 16 + 6 + 12)).
